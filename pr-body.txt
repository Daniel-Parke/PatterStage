## Latest changes (this session)

### Review findings (List 4: Models, HERMES.md, Environment, Settings) — 2026-05-28 (session 20)

**Critical runtime bug fixed — ensureProfileAuth hardcoded MINIMAX_API_KEY:**
- `src/lib/backends/hermes.ts` `ensureProfileAuth()` wrote `MINIMAX_API_KEY=***` to the profile .env regardless of the actual provider
- Any non-minimax provider (anthropic, openai, etc.) would incorrectly write MINIMAX_API_KEY when dispatching missions for non-default profiles
- Fix: added `provider` parameter to `ensureProfileAuth()`, derive correct env var via `envVarForProvider()` from `hermes-providers`, skip .env write for OAuth-only providers (nous, etc.)
- Also fixed auth.json credential pool to use the actual provider key instead of hardcoded "minimax"

**ConfigSectionPage hasChanges computation bug:**
- `hasChanges` for file sections (HERMES.md, .env) was using `yamlHasChanges` useMemo instead of `fileContent !== originalFileContent`
- `yamlHasChanges` computed `JSON.stringify({}) !== JSON.stringify({})` = false, but the inline comparison was replaced with a useMemo that wasn't being recomputed on file changes
- Fix: extract `fileHasChanges` as a separate useMemo, use it in the `hasChanges` conditional

All 630 tests pass.
