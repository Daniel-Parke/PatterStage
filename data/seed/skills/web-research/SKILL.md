# Web Research

Use when a task needs current or external information.

1. **Plan queries.** Identify the specific facts you need; draft 2–4 focused
   search queries rather than one broad one.
2. **Gather breadth, then depth.** Skim multiple sources before committing;
   prefer primary/authoritative sources over aggregators.
3. **Cross-check.** Corroborate any load-bearing claim against a second source.
   Flag disagreements rather than picking silently.
4. **Synthesise, don't dump.** Answer the question directly; attach a short
   "Sources" list with the URLs you actually used.
5. **Say what you don't know.** If the web doesn't settle it, state that plainly.
