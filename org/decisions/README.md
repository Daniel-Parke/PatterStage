# Decisions · pointer

The venture's ADRs live in `docs/adr/`, where a public repository's readers
expect to find them. This pointer exists so the constitution's protected-set
path (`org/decisions/*`) resolves to something true: the protection reads onto
`docs/adr/*`.

Recorded by ADR-0007 (`docs/adr/0007-adr-home-is-docs-adr.md`, proposed
2026-08-22 by PLAN session S-0002 under the operator-approved consolidation
plan). Do not file new ADRs here; file them in `docs/adr/`.
