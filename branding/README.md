# Official branding

This directory holds PatterStage and PatterTech visual identity, colour guidelines, and logos or icons as they are added.

**Not open source.** See [LICENSE.md](LICENSE.md). Do not reuse or redistribute these files in your own project.

If you fork the software, remove this directory and create your own branding. See [../REBRANDING.md](../REBRANDING.md).
